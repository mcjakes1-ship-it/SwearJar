OBS WEBSOCKET SETUP

To enable Kill Stream, do this one-time setup in OBS:

  1. In OBS, click Tools in the top menu
  2. Select WebSocket Server Settings
  3. Check Enable WebSocket Server
  4. Uncheck Enable Authentication
  5. Click OK — done

No password needed for local connections. The overlay handles the rest automatically.
